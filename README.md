# Автопостер рилсов в Instagram

Скрипт сам публикует рилсы в Instagram (@dayzerorules) из папки `queue/`.
Работает на серверах GitHub, твой компьютер для этого не нужен.

## Как это устроено

Одно длинное видео = одна папка = рилсы на один день.

```
queue/
  001_podcast/          ← день 1
    01.mp4  01.txt  01.jpg
    02.mp4  02.txt
    ...
  002_interview/        ← день 2
    01.mp4  01.txt  01.jpg
    ...
```

- Каждый день берётся **следующая папка по алфавиту** (поэтому нумеруй: `001_`, `002_`, …).
- Её рилсы выходят **равномерно с 10:00 до 22:00 по Москве**. Например, 7 рилсов: 10, 12, 14, 16, 18, 20, 22 часов; 6 рилсов: примерно каждые 2,5 часа.
- Внутри папки рилсы идут по алфавиту: `01`, `02`, …
- Когда папка опубликована целиком, она переезжает в `posted/`. Ссылки на рилсы пишутся в `state.json`.
- Если папки в очереди закончились, скрипт просто ждёт новые.

Файлы для каждого рилса (имена совпадают, отличается только расширение):

| Файл | Что это | Обязательно |
|---|---|---|
| `01.mp4` | видео (вертикальное 9:16, до 15 минут) | да |
| `01.txt` | описание к рилсу, весь текст как есть, с хэштегами | нет |
| `01.jpg` | обложка (лучше 1080×1920) | нет |

Без обложки берётся кадр с 1-й секунды. Без `.txt` подпись будет пустой (или `default_text` из настроек).

## Как загрузить папку

На сайте GitHub: открой `queue/` → **Add file → Upload files** → перетащи всю папку целиком → **Commit changes**.
Через сайт можно загрузить файл до 25 МБ. Крупнее нужно сжать или загрузить через GitHub Desktop (до 100 МБ).

Загружай папку **до 10:00 МСК** дня публикации. Если загрузить позже, рилсы распределятся на остаток дня.

## Настройка (один раз)

1. Репозиторий публичный: так Instagram может забрать обложку по ссылке.
2. **Settings → Secrets and variables → Actions → New repository secret**, добавь:
   - `IG_TOKEN`: токен Instagram
   - `IG_USER_ID`: `17841431768361264`
   - `GH_PAT` (для автопродления токена): Fine-grained token на github.com/settings/tokens
     с доступом только к этому репозиторию и правом **Secrets: Read and write**.
3. Вкладка **Actions** → «Публикация рилсов» → **Run workflow** → `check`. Должно написать «Токен работает».

Посмотреть, какие подписи и в какое время выйдут, без публикации: Run workflow → `dry-run`.

## Настройки в `config.json`

- `day_start`, `day_end`: окно публикаций (по умолчанию `10:00` и `22:00`)
- `timezone`: часовой пояс (по умолчанию `Europe/Moscow`)
- `hashtags`: хэштеги, которые добавляются к каждому рилсу, например `"#dayzero #reels"`
- `default_text`: подпись для видео без `.txt`
- `thumb_offset_ms`: с какой миллисекунды брать кадр для обложки, если нет `.jpg`
- `share_to_feed`: показывать ли рилс в сетке профиля

## Токен

Токен живёт 60 дней. Workflow «Продление токена» раз в неделю продлевает его и, если задан `GH_PAT`,
сам сохраняет новый в `IG_TOKEN`. Без `GH_PAT` продлённый токен придётся вставлять вручную.

## Если что-то пошло не так

Actions → открой красный запуск → там текст ошибки. Рилс, который не удалось опубликовать 3 раза подряд,
пропускается и записывается в `state.json` → `skipped`. Чтобы попробовать снова, удали его оттуда.
GitHub запускает задачи по расписанию с опозданием до 5–30 минут, это нормально.

## Виджет для Windows

Маленькое окно: перетаскиваешь в него папку с рилсами, и оно само загружает её в `queue/`
под следующим номером (`002_имя`, `003_имя`, …) одним коммитом. Сайт GitHub для этого не нужен,
а лимит на файл не 25, а 95 МБ.

1. Скачай `ReelsWidget.exe` со страницы [Releases](../../releases/tag/widget) и запусти.
   Windows может предупредить «неизвестный издатель»: **Подробнее → Выполнить в любом случае**.
2. При первом запуске виджет попросит токен GitHub. Создай его на github.com/settings/personal-access-tokens:
   **Generate new token** → Repository access: **Only select repositories → autopostreels** →
   Permissions: **Contents: Read and write** → Generate. Токен хранится в диспетчере учётных данных Windows.
3. Перетащи папку в окно. Внизу видна очередь: какие папки ждут публикации.

Свой номер в начале имени папки виджет заменит на следующий по порядку.
В папку берутся `.mp4 .mov .txt .jpg .jpeg .png .srt`, остальное игнорируется.

### Мониторинг в виджете

Под полем для папки есть плашка «Сегодня: 1 из 4 опубликовано, следующий в 18:00». Нажми её, и раскроются две вкладки:

- **План на сегодня**: время и название каждого рилса со статусом (вышел, ждёт, пропущен).
- **Результаты**: по каждому вышедшему рилсу лайки и комментарии, а просмотры, если токену Instagram выдано разрешение `instagram_manage_insights`.

Двойной щелчок по строке открывает рилс в Instagram. Данные обновляются сами раз в 5 минут. Результаты собирает автопостер раз в час (`stats.json`).

### Внешний вид и настройки виджета

Тёмный интерфейс с карточками. Перед загрузкой виджет показывает предпросмотр папки: сколько видео, описаний и обложек, чего не хватает. Шестерёнка справа вверху открывает настройки:

- **Подключение**: репозиторий, ветка, токен GitHub и кнопка «Сохранить и проверить».
- **Вид**: тема (системная, тёмная, светлая), **эффект стекла** (Mica, Acrylic или размытие Windows 10), прозрачность окна, размер интерфейса, «поверх остальных окон».
- **Работа**: автообновление данных, часовой пояс, «загружать сразу после перетаскивания».

Если стекло выглядит плохо или глючит, выбери в «Вид» → «Эффект стекла» вариант «Выкл».
