# Reels Studio

Приложение для Windows: из записи стрима делает вертикальные нарезки для TikTok и Reels и складывает их
в папку, которую понимает автозалив этого репозитория.

**Скачать:** [Releases → studio → ReelsStudio-Setup.exe](https://github.com/Frizy229/autopostreels/releases/tag/studio).
Установщик собирается из `main` workflow «Сборка Reels Studio для Windows».

## Первый запуск

1. **Настройки → Компоненты:** скачай yt-dlp, whisper.cpp и модель речи (`large-v3-turbo`, 1.6 ГБ, для RTX 3070).
   ffmpeg уже внутри. Нажми «Проверить» у кодировщика NVIDIA: если не работает, выбери «Процессор».
2. **Монтаж:** отметь раскладки и стили субтитров. Для раскладки «Стрим сверху, мини-игра снизу» выбери папку
   со своими роликами мини-игр (Subway, паркур, Minecraft и т. п.).
3. **Каналы и тексты:** число каналов, их имена (как аккаунты в автозаливе), роликов на канал, подписи, комментарий.

## Как делать нарезки

1. **Поиск:** быстрые кнопки «Записи стримов Twitch», «YouTube: эвелон стрим»… или своя ссылка, или файл с диска.
   «В работу» добавляет видео в «Моменты».
   Если YouTube пишет «Sign in to confirm you're not a bot», войди в YouTube в Firefox, закрой Firefox и повтори.
   Программа сама подхватит cookies; браузер или файл cookies.txt можно выбрать в Настройках → «Вход в YouTube».
   Twitch и файлы с диска работают без входа.
   Если YouTube не открывается вообще («Failed to resolve www.youtube.com»), включи VPN. Программа сама берёт прокси, который VPN ставит в Windows.
   Если VPN работает только в браузере, укажи его прокси в Настройках → «Сеть» и нажми «Проверить YouTube».
1a. **Фон:** залипательные видео и мини-игры для низа (чистка ковров, ржавое, слаймы…). Выбери превью и нажми
   «В библиотеку»: видео скачается в папку фона, монтаж возьмёт его сам. «Только Creative Commons» — меньше риска жалоб.
2. **Моменты:** «Рамка вебки»: зелёные рамки — вебки (можно до 4, «Ещё вебка», крестик убирает), пунктир — контент; «Найти лица» ставит рамки сами. Нет вебки — «Без вебки».
   «Найти моменты» слушает звук и чат и предлагает отрезки. Впиши заголовки («строка 1 | строка 2»),
   сними лишнее, отметь «Эвелон главный», нажми «Проверить» (распознаёт речь и проверяет правила).
3. **Сборка:** «Собрать N роликов». Готовая папка — в «Документы/Reels Studio/queue/NNN_имя/».
   Её можно загрузить виджетом как обычную папку.

## Что внутри папки

```
queue/017_evelone-stream/
  texts.json                 ← комментарий для всех роликов (Instagram)
  evelon185/                 ← канал 1: свои ролики
    short-1-kontrataka.mp4   1080×1920, 30 к/с, H.264, AAC, −14 LUFS
    short-1-kontrataka.txt   TITLE / REELS CAPTION (Instagram) / REELS CAPTION (TikTok) / COVER
    cover-1.jpg
    …
  channel2/ …
```

При одном канале подпапок нет. В каждой подписи и в TITLE обязательно есть `#evelone` и `twitch: evelone2004`
(меняется в «Каналы и тексты → Правила конкурса»).

## Правила конкурса

Перед сборкой каждый выбранный момент проверяется: в нём должна звучать речь (по умолчанию не меньше 25% времени
и 12 слов, иначе «молча смотрит»), у раскладок с вебкой должна быть задана рамка вебки. Не прошедшие моменты
в папку не попадают и перечислены в окне сборки. Что именно Эвелон «главное лицо» и мем оригинальный, программа
проверить не может: для этого галочка «Эвелон главный» и переключатель «Только отмеченные мной».

## Для разработки

```
cd studio-app
npm install
npm start          # окно
npm test           # 12 наборов: раскладки, субтитры, моменты, каналы, выход, правила, источники, речь, рендер,
                   # настройки, окно, компоненты; сквозной тест конвейера на настоящем ffmpeg (Linux/macOS)
npm run icons      # обновить иконки Lucide в renderer/icons
```

Код: `lib/` — чистая логика (раскладки `layout.js`, субтитры ASS `subs.js`, моменты `moments.js`, раздача по каналам
`plan.js`, выходная папка `output.js`, правила `rules.js`, yt-dlp `sources.js`, whisper.cpp `transcribe.js`,
ffmpeg `render.js`, конвейер `pipeline.js`), `main.js` — окно и задачи, `renderer/` — интерфейс.
Снимки всех страниц: `STUDIO_SHOTS=папка npm start`.
История: [docs/WORKLOG.md](../docs/WORKLOG.md), баги: [docs/BUGFIXES.md](../docs/BUGFIXES.md).
Шрифты субтитров (Montserrat, Unbounded, Rubik, Russo One) и иконки Lucide — под открытыми лицензиями OFL/ISC.

## Автопостер

После «Собрать» папка сама уходит в виджет Reels Widget. Это включено переключателем «Сразу в автопостер» на экране сборки.
Виджет должен быть запущен и подключён к GitHub. Он загружает папку в очередь, выбранную в поле «Очередь автозалива» (например, «Только TikTok»).
Имена каналов должны совпадать с аккаунтами автопостера. Их можно взять кнопкой «Каналы и тексты → Взять аккаунты из автопостера».

## Группы аккаунтов

Если в автопостере есть группы аккаунтов (виджет 4.7.0 и новее), в разделе «Instagram» сверху выбирается группа. Показываются аккаунты этой группы, папка уходит в очередь этой группы. Виджет обновляет список раз в 5 минут, кнопка «Обновить» читает его заново.

## Instagram

Раздел «Instagram» собирает рилсы под выбранные аккаунты Instagram из автопостера и сразу отдаёт папку виджету.
Отметь аккаунты, выбери, сколько роликов на аккаунт и какие раскладки, задай подпись и закреп, потом нажми «Собрать и отправить».
Режим «Первый ролик сразу» публикует по одному ролику на каждый аккаунт сразу после загрузки. Остальные ролики выходят по расписанию автопостера.
Для этого токену GitHub в виджете нужно право Actions: Read and write.

## Рилсы, лонги, обрезка и блюр

На вкладке «Поиск» в поле ссылок можно вставить сразу несколько ссылок: Instagram Reels, YouTube (лонги и шортсы), Twitch, Kick, VK.
Instagram часто не отдаёт рилсы без входа. Тогда войди в Instagram в Firefox, закрой его и повтори (Настройки → «Вход на сайты»). Профиль целиком не скачивается, нужны ссылки на сами рилсы.
Кнопка с ножницами у момента открывает окно «Обрезка и блюр». Там ставятся начало и конец и размытые рамки (ник, вотермарка, лицо, чужой чат) на всё видео или на время.

## Умный отбор моментов

Поиск берёт вдвое больше кандидатов и проверяет каждого: картинку (чёрный экран, замерший кадр), речь (слов мало, музыка, ровный звук) и признаки смешного (смех в речи и в подписях whisper, реакция чата, скачки громкости). Мусор снимается с выбора, причина видна в списке. Выключается в Настройках. Для проверки речи нужен компонент «распознавание речи».

## Нейросеть для смешного

Настройки → Компоненты: «Нейросеть: программа» (llama.cpp) и «Нейросеть: модель» (Qwen2.5 7B, 4,7 ГБ, или лёгкая 3B). После установки «Найти моменты» дополнительно читает текст каждого момента и ставит 0–10. Оценка видна в плашке и двигает момент в списке. Работает локально, без ключей. Нужно распознавание речи: нейросеть читает его текст.

## Заносы в казино

Кнопка «Найти заносы» рядом с «Найти моменты». Момент выбирается по сигналам: иксы и плашка WIN на экране (читаются локально, tesseract), рост счётчика выигрыша, резкий крик, слова «занос / макс вин / иксы», всплеск чата, оценка нейросети. Пустые вращения и дубли снимаются с причиной, границы ставятся с подводкой и концовкой по паузам речи. В списке видно, почему выбран момент (x, сумма, плашка). Нужны компоненты распознавания речи (для слов) и, по желанию, нейросеть; чтение экрана выключается в Настройках.

## Поиск по YouTube, Twitch и Instagram

Под строкой поиска можно выбрать, где искать: везде, только YouTube, только Twitch или только Instagram.
В Twitch ищутся записи, хайлайты и клипы каналов из поля «Twitch-каналы» по словам в названии.
Instagram ищет рилсы по хэштегу («#evelone» или «эвелон») через официальный API Meta. Для этого один раз вставь токен Instagram в Настройках → «Поиск в Instagram».
