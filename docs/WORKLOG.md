## 2026-11-05 · Виджет 4.0.0: разделы Instagram и TikTok

Запрос Alex: разделить интерфейс на Instagram и TikTok, разные папки для разных сетей, тексты/комментарии,
которые сами прикрепляются при заливе, современный дизайн, тесты автозалива в обе сети.

Автопостер (`autoposter.py`):
- Отдельные очереди `queue-instagram/` и `queue-tiktok/` со своим расписанием (своя папка дня и план).
  Общая `queue/` работает как раньше (во все аккаунты). Опубликованное едет в `posted-instagram/`, `posted-tiktok/`.
- Ключи в `state.json` для отдельных очередей с приставкой `instagram:` / `tiktok:`; расписание очередей в `state.lanes`.
  Старые записи не трогаются, общая очередь хранится как раньше.
- Пауза соцсети (`paused` в `config.json`); после снятия остаток дня распределяется заново с текущего момента.
- Тексты по умолчанию для каждой сети (`texts`) и на папку (`texts.json`): подпись по умолчанию, хвост подписи, хэштеги.
- Первый комментарий под рилсом в Instagram (`comment`, раздел `COMMENT:` в .txt, по желанию `PINNED COMMENT:`).
  Ошибка комментария не ломает публикацию. TikTok комментарии от программ не разрешает.
- `--only` и `remove` понимают приставки очередей; `dry-run` показывает все очереди, подписи и комментарии.
- Workflow публикации сохраняет новые папки очередей; новый workflow «Тесты» гоняет все тесты на каждый PR.

Виджет (`widget-app`, 4.0.0):
- Новый интерфейс: вкладки Instagram / TikTok с цветом сети, панель сети (аккаунты, режим, пауза, тексты, запуск),
  план дня и очередь своей сети, папки общей очереди с пометкой «обе сети».
- Загрузка: выбор очереди (Instagram / TikTok / обе сети) и тексты папки прямо при загрузке.
- Тексты сети и папки с живым примером итоговой подписи.
- «Опубликовать сейчас» для одного ролика и «Запустить» (запуск workflow на GitHub, нужно право токена Actions).
- TikTok: экран подтверждения прямой публикации теперь и для `queue-tiktok/`; подпись подставляется из блока TikTok.
- Отметка у рилса, добавился ли авто-комментарий.
- Релиз виджета собирается только из main (сборка в ветке PR лишь проверяет, что всё собирается); в сборке гоняются все тесты.

Тесты: автопостер 95 (было 68), виджет 5 наборов (добавлены `lanes.test.js`, `ui.test.js`).
Проверено: интерфейс в настоящем Electron под Xvfb (запуск без токена, оба раздела, ошибка запуска без права Actions)
и снимки экрана на данных из `state.json`.
