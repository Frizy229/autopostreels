# Исправленные баги

Новое сверху. Формат: что было → почему → что сделано. История работы: [WORKLOG.md](WORKLOG.md).

## 2026-11-05 · Reels Studio 0.1.0

1. **Окно приложения было пустым.** В `app.js` функция называлась `api`, а preload уже кладёт `window.api`:
   объявление в общей области падало с SyntaxError, и скрипт не выполнялся вовсе. Переименовано в `call`.
   Найдено запуском настоящего Electron (снимки страниц под Xvfb).
2. **Рамка у верхнего/левого края съезжала на 2 пикселя**: координата округлялась функцией для размеров с минимумом 2,
   поэтому 0 становился 2. Для координат теперь своё округление (тест `layout.test.js`).
3. **Один момент у двух каналов выходил в одной и той же раскладке**, если раскладок две: индекс «канал + повтор»
   совпадал. Теперь у повтора момента берётся раскладка и стиль субтитров, которых у этого момента ещё не было.
   Найдено сквозным тестом конвейера.
4. **Канал без имени превращался в «[object Object]»** при чтении настроек. Исправлен разбор списка каналов.
5. **`#evelone2004` засчитывался за `#evelone`** при проверке обязательного хэштега. Теперь хэштег сравнивается целиком.
6. **Цвет подсветки в субтитрах писался в формате стиля** (`&H00BBGGRR` без закрывающего `&`) прямо в тег текста.
   libass его понимал, но это не по формату ASS. Для тегов отдельная функция `tagColor`.
9. **«В релизе whisper.cpp нет сборки для Windows ()» в Настройках → Компоненты** (нашёл Alex).
   Программа смотрела релиз с пометкой «Latest» (v1.9.5), а там только исходники: готовые сборки whisper.cpp
   выкладывает в пре-релизы `bNNNN`, и называются они теперь `whisper-bin-win-cuda-12.4.0-x64.zip`, а не `cublas`.
   Теперь берутся последние 20 релизов, выбирается CUDA 12 x64 (для RTX 3070), запасные — `whisper-blas-bin-x64.zip`
   и `whisper-bin-x64.zip`. После распаковки сборка проверяется запуском; не запустилась — ставится следующая.
   Тест на настоящих именах файлов релиза b5454 (`tools.test.js`). Версия 0.1.1.
8. **Workflow «Тесты» на main упал после PR #7**: `spawn …/@ffprobe-installer/linux-x64/ffprobe EACCES`.
   CI ставит пакеты с `npm ci --ignore-scripts`, а право на выполнение ffprobe выдаёт как раз скрипт пакета.
   Теперь программа сама выдаёт право бинарнику из пакета, а если не может — берёт системный ffprobe/ffmpeg
   (`runnable` в `lib/tools.js`, тест в `tools.test.js`). Повторено снятием права локально.
7. **Сборка падала целиком, если видеокарта не кодирует** (нет NVENC, старый драйвер). Теперь ролик доделывается
   на процессоре, остальные тоже, а в окне видно предупреждение.

## 2026-11-05 · Виджет 4.0.0 и автопостер

1. **Окно настроек не открывалось само, когда нет токена GitHub.**
   Ошибка из main-процесса проходит через contextBridge, а он у ошибок оставляет только текст: код `NO_TOKEN` терялся,
   и вместо подсказки виджет писал «Не удалось обновить». Теперь preload передаёт ответ целиком, ошибку с кодом собирает окно.
   Найдено запуском настоящего Electron без токена.
2. **Превью TikTok могло показать прошлое видео.** Каждое видео скачивалось в один и тот же файл `reels-preview.mp4`,
   и окно брало его из кэша по тому же адресу. Теперь имя файла уникальное, старые превью удаляются.
3. **Ошибка загрузки превью TikTok сразу стиралась** проверкой формы (поле ошибок перезаписывалось). Теперь сообщение
   показывается под видео и не пропадает.
4. **Подсказка подписи на экране подтверждения TikTok бралась неправильно**: первая строка .txt, то есть `TITLE`,
   а не блок `REELS CAPTION (TikTok)`. Теперь подпись выбирается так же, как в автопостере (блок аккаунта → блок TikTok → общий),
   и к ней добавляются хвост и хэштеги TikTok.
5. **Окно мигало при любой смене настройки** (например, раздела): каждый раз заново применялся материал окна и автозапуск.
   Теперь только когда меняли именно их.
6. **Рилс, вышедший в Instagram и пропущенный в TikTok, навсегда оставался «частично 1/2»**, а пропуск у первого аккаунта
   делал весь рилс «пропущен», даже если другие ещё ждали. Теперь: вышел везде, где не пропущен → «вышел»; «пропущен» только если пропущен везде.
7. **Сборка виджета проверяла не все тесты**: workflow сборки виджета запускал только `core.test.js`,
   тесты GitHub и TikTok не запускались. Теперь `npm test` (все наборы), плюс workflow «Тесты» для Python и виджета на каждый PR.
8. **Релиз виджета подменялся сборкой из любой ветки**: push в ветку PR публиковал новый `ReelsWidget-Setup.exe` до слияния.
   Теперь релиз только из main.
9. **Папка без аккаунтов «заканчивалась» сама**: если у очереди нет ни одного аккаунта (например, TikTok без токена),
   все её ролики считались опубликованными и папка уезжала в posted. Добавлена защита (тест `test_no_accounts_lane_not_swept`).
10. **Часы в шапке подписаны «Москва UTC+3»**, хотя расписание по Томску. Теперь показывается время часового пояса расписания и окно публикаций.
