# Группы: отдельная сетка аккаунтов для другого проекта

**Группа** — это своя сетка аккаунтов Instagram и/или TikTok под другой тип видео. У каждой группы:

- свои аккаунты (ролики группы выходят только в них);
- свои очереди: общая (в обе сети), только Instagram, только TikTok;
- своё окно публикаций (например, 12:00–20:00), свои тексты, хэштеги и комментарий;
- своя пауза: остановил одну группу, остальные работают.

Всё, что было до групп (аккаунты @dayzerorules, @rulezerosurvivel, @survivelzerorule, @evelon185 и папки `queue…/`),
теперь называется **группой «Основная»** и работает как раньше. Переносить ничего не нужно.

Нужен виджет **4.5.0** или новее: [скачать](https://github.com/Frizy229/autopostreels/releases/tag/widget)
(после слияния PR в main релиз соберётся сам).

---

## Шаг 1. Создать группу (1 минута)

1. В виджете вверху нажми на плашку **«Группа: Основная ▾»** (или `Ctrl+G`).
2. **«+ Новая группа»** → впиши название (например, «Машины»).
3. По желанию задай окно: **Первый ролик дня** и **Последний** (например, `12:00` и `20:00`, время Томска).
   Пусто — как в основной группе (10:00–22:00).
4. **«Создать»**. Виджет сразу переключится на новую группу и покажет план «с чего начать».

Группа появится в `config.json` в разделе `groups`, её папки будут в `groups/<id>/` (id виджет делает из названия
латиницей: «Машины» → `mashiny`).

Переключать группы: та же плашка вверху, или `Alt+1`, `Alt+2`, `Alt+3`… (номер по списку).
Переименовать группу, поменять окно или убрать пустую группу: карандаш у группы в списке.

## Шаг 2. Подключить аккаунты Instagram через Facebook

Сначала убедись, что вверху выбрана **нужная группа**: новые аккаунты попадают в открытую группу.

### Один раз для всего приложения (если ещё не делал для основной группы, иначе пропусти)

1. Токену GitHub виджета нужно право **Secrets: Read and write**:
   [токены GitHub](https://github.com/settings/personal-access-tokens) → токен виджета → Edit →
   Repository permissions → Secrets → Read and write.
2. Ключи приложения Meta: [Мои приложения](https://developers.facebook.com/apps/) → приложение **Auto** →
   Настройки приложения → **Основное** → скопируй «ID приложения» и «Секрет приложения» → в виджете
   раздел Instagram → «+ аккаунт» → вставь в поля «ID приложения Meta» и «Секрет приложения Meta» → «Сохранить ключ».
3. Продукт **«Вход через Facebook»** у приложения и адрес возврата `https://frizy229.github.io/autopostreels/`
   (Вход через Facebook → Настройки → «Действительные URI перенаправления для OAuth»).
   Подробно со скриншотами: [accounts-setup.md](accounts-setup.md#один-раз-подготовка).

### Каждый новый аккаунт Instagram (~2 минуты)

1. В приложении Instagram на этом аккаунте: Профиль → ☰ → «Тип аккаунта и инструменты» →
   **«Переключиться на профессиональный»** → «Автор» или «Бизнес».
2. Создай **Страницу Facebook** для этого аккаунта: [создать Страницу](https://www.facebook.com/pages/create)
   (у каждого аккаунта Instagram своя Страница).
3. Привяжи Instagram к Странице: [Meta Business Suite](https://business.facebook.com/latest/settings/) → выбери
   Страницу слева вверху → Настройки → «Аккаунты Instagram» → «Подключить» → войди в Instagram.
4. В виджете (открыта нужная группа!) → вкладка **Instagram** → **«+ аккаунт»** → **«Войти через Facebook»** →
   «Изменить настройки» → отметь **все** Страницы и аккаунты → «Продолжить».
5. В списке новые аккаунты уже отмечены и подписаны «новый → в группу «Машины»». Аккаунты, которые уже есть в
   другой группе, подписаны её названием: если отметишь их, им просто обновится вход, а сами они останутся в своей
   группе. **«Сохранить отмеченные»**.

Можно привязать сразу несколько аккаунтов к Страницам и добавить их одним входом.
Токен каждого аккаунта ляжет в секрет `IG_TOKEN_<НИК>`; продлевается сам раз в неделю (как в основной группе).

> Один ник может быть только в одной группе: по нику автопостер запоминает, что уже вышло. Нужен тот же аккаунт
> в другой группе — сначала убери его из старой (нажми на аккаунт → «Убрать»).

## Шаг 3. Подключить TikTok

1. Один раз: Client secret приложения TikTok
   ([developers.tiktok.com → Manage apps](https://developers.tiktok.com/apps/) → приложение → вкладка Sandbox,
   пока приложение в песочнице → Client secret) → в виджете вкладка TikTok → «+ аккаунт» → вставь → «Сохранить ключ».
2. Пока приложение в песочнице, аккаунт должен быть в списке **Target users** (там же, Sandbox → Target users).
3. Вкладка **TikTok** (в нужной группе) → **«+ аккаунт»** → «Войти в TikTok» → войди → «Разрешить» → впиши ник →
   «Сохранить аккаунт». Режим «В черновики» работает без аудита: ролик приходит уведомлением в приложение TikTok.

Подробнее про режимы и аудит: [tiktok-setup.md](tiktok-setup.md).

## Шаг 4. Куда класть ролики

Проще всего — виджетом: открой группу вверху, выбери вкладку сети и **перетащи папку в окно** (или «+» внизу).
В окне загрузки видно «Группа: Машины», путь и куда выйдут ролики:

| Кнопка в окне загрузки | Папка на GitHub | Куда выходит |
|---|---|---|
| Instagram | `groups/<id>/queue-instagram/NNN_имя/` | все Instagram-аккаунты группы |
| TikTok | `groups/<id>/queue-tiktok/NNN_имя/` | все TikTok-аккаунты группы |
| Обе сети | `groups/<id>/queue/NNN_имя/` | все аккаунты группы |

Папка устроена как раньше:

- **плоская** — `short-1.mp4`, `short-1.txt`, `cover-1.jpg`, … : каждый ролик уходит во все аккаунты очереди;
- **с подпапками по аккаунтам** — `carsdaily/short-1.mp4`, `carsdaily2/short-1.mp4`: каждый аккаунт получает свои
  ролики (имя подпапки = ник аккаунта этой группы).

Одна папка = один день: ролики равномерно распределяются в окне группы. Опубликованная папка переезжает в
`groups/<id>/posted…/`. Подпись берётся из `.txt` (раздел `REELS CAPTION`), обложка — `cover-N.jpg`.

Вручную через GitHub тоже можно: положи папку в `groups/<id>/queue-instagram/` (и т. д.) в
[репозитории](https://github.com/Frizy229/autopostreels).

## Шаг 5. Тексты, пауза, запуск

В открытой группе на вкладке сети:

- **Тексты** — подпись по умолчанию, хвост подписи, хэштеги, первый комментарий (Instagram). У каждой группы свои.
- **Пауза** — останавливает только эту сеть в этой группе. Остальные группы публикуют дальше.
- **Запустить** — запускает автопостер сейчас (публикует то, что пора по плану во всех группах).
- Молния у ролика — опубликовать его сейчас, вне расписания.

## Как это хранится (для справки)

`config.json`:

```json
{
  "accounts": [ … аккаунты основной группы, как раньше … ],
  "groups": [
    {
      "id": "mashiny",
      "name": "Машины",
      "day_start": "12:00",
      "day_end": "20:00",
      "accounts": [
        { "name": "carsdaily", "token_env": "IG_TOKEN_CARSDAILY", "user_id": "1784…" },
        { "name": "carstok", "platform": "tiktok", "mode": "inbox", "token_env": "TT_TOKEN_CARSTOK" }
      ],
      "texts": { "instagram": { "footer": "Подпишись!" } },
      "hashtags": "#cars",
      "paused": []
    }
  ]
}
```

- Группа может задать своё `day_start`, `day_end`, `hashtags`, `default_text`, `caption_template`, `texts`, `paused`.
  Часовой пояс и лимит публикаций за запуск общие.
- В `state.json` расписание группы лежит в `lanes["mashiny"]`, `lanes["mashiny:instagram"]`, `lanes["mashiny:tiktok"]`,
  опубликованное — в `posted_acc[<ник>]` с ключами вида `mashiny:instagram:001_x/short-1.mp4`.
- `--only` и `remove` понимают приставку группы: `mashiny:instagram:001_x/short-2.mp4`, `mashiny:005_x`.
- Сломанный токен аккаунта группы не останавливает публикацию в других группах.
- Workflow `post.yml` не менялся: папки `groups/` автопостер сам добавляет в коммит.

## Если что-то не так

- Аккаунт с красной точкой: нажми на него → «Переподключить».
- «Ник уже есть в группе …»: этот аккаунт подключён в другой группе, убери его там или выбери другой ник.
- Ролики не выходят: проверь окно группы (карандаш у группы) и паузу; журнал запусков —
  [Actions](https://github.com/Frizy229/autopostreels/actions).
- Убрать группу можно, только когда в ней нет аккаунтов и папок в очереди.
